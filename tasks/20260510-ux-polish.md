# 20260510-ux-polish

**Status:** READY_FOR_DEV
**Created:** 2026-05-10

## Goal

Polish the browse UI: remove the left filter sidebar entirely, kill the search suggestions popover, add subtle card entry animations, add a "Trending" and "Top Rated" landing-page section (score-based sort as data proxy until the pipeline task delivers real `chart_rank`), and drop Japan from the entire frontend.

## Acceptance criteria

- [ ] `FilterSidebar` component is not rendered anywhere — desktop `<aside>` and mobile bottom-sheet are gone; the "My Providers" provider-picker button in the header remains.
- [ ] `search-bar.tsx` no longer shows a suggestions dropdown on any viewport. Typing instantly filters the card grid via `onSearch`. The `/` focus hotkey and the Esc/clear behaviour stay; the arrow-key suggestion-navigation hotkeys are removed.
- [ ] `globals.css` defines `@keyframes card-in` (fade + translateY). `TitleCard` applies `animation: card-in 180ms ease both` with a staggered `animation-delay` via a CSS custom property `--card-i` (capped at 24 items to avoid long cascades). `@media (prefers-reduced-motion: reduce)` disables all card animations.
- [ ] On the landing page (no query, no active providers filter), a "Trending" horizontal-scroll rail appears above the result grid, showing the top 20 titles sorted by `chart_rank ASC` (nulls last), falling back to `imdb_score || tmdb_score DESC` when `chart_rank` is null. A "Top Rated" rail shows below it (top 20 by `imdb_score DESC`, requiring imdb_score > 0). Both rails disappear the instant any search query or provider filter becomes active.
- [ ] `CountryCode` type no longer includes `'JP'`; `COUNTRIES` array in `country-switcher.tsx` no longer lists JP; `DEFAULT_LANGUAGE` map has no JP key; the JP SVG in `flag.tsx` is removed.
- [ ] `npm run build` succeeds with no TypeScript errors after all changes.

## Constraints / non-goals

- Do NOT remove the `filter-sidebar.tsx` file itself yet (the Reviewer may want to archive it). Just stop importing/rendering it.
- Do NOT add Framer Motion or any animation library — pure CSS only.
- Do NOT implement a new genre/type filter UI as a replacement. The sidebar is simply gone.
- Do NOT change the `provider-picker.tsx` component or the "My providers" feature.
- The Trending rail uses `chart_rank` from `Title` (a new optional field added to the `Title` interface in `data.ts` and `wire.ts`). Since existing catalog JSONs don't have the `cr` wire key yet, `chart_rank` will be `null` for all titles in the current data — the fallback sort kicks in automatically. This is correct and intentional.
- Japan data files in `data/` and `web/public/data/` are left on disk (pipeline task removes them).

## Affected docs (developer must update or prune)

- `docs/features/streaming-web-app.md` — update Mobile layout, Filter sidebar, and Country sections; remove JP references; document the Trending/Top Rated rails.

### 4. Trending + Top Rated sections

Add these to `routes/index.tsx`. Only visible when `!searchParams.q && myProviders.length === 0` (no active query, no provider filter). Use the full `titles` array (not `filteredTitles`) so the rail always shows global top content.

```tsx
// Trending rail (shown on landing)
const trendingTitles = useMemo(() => {
  return [...titles]
    .filter(t => t.available_on_flatrate.length > 0)
    .sort((a, b) => {
      const ar = a.chart_rank, br = b.chart_rank
      if (ar !== null && br !== null) return ar - br
      if (ar !== null) return -1
      if (br !== null) return 1
      const sa = a.imdb_score ?? a.tmdb_score ?? 0
      const sb = b.imdb_score ?? b.tmdb_score ?? 0
      return sb - sa
    })
    .slice(0, 20)
}, [titles])

// Top Rated rail
const topRatedTitles = useMemo(() => {
  return [...titles]
    .filter(t => t.available_on_flatrate.length > 0 && (t.imdb_score ?? 0) > 0)
    .sort((a, b) => (b.imdb_score ?? 0) - (a.imdb_score ?? 0))
    .slice(0, 20)
}, [titles])
```

Render them as a horizontally-scrolling poster rail above the result grid. Example markup (Tailwind):

```tsx
<section>
  <h2 className="text-lg font-semibold px-4 pt-4 pb-2">Trending now</h2>
  <div className="flex gap-3 overflow-x-auto px-4 pb-4 scrollbar-thin">
    {trendingTitles.map((t, i) => (
      <div key={t.jw_entry_id} className="flex-shrink-0 w-28 sm:w-36">
        <TitleCard title={t} onClick={() => navigate(...)} index={i} />
      </div>
    ))}
  </div>
</section>
```
